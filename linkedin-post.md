🗺️ Most Power BI maps look the same. So I built one that isn't a map at all.

👇 Every coloured tile below is a plain MATRIX CELL.

No map visual. No shape map. No custom visual. No Azure Maps.
Just a grid of cards arranged to look like Melbourne. 🇦🇺

📊 Each card = one suburb
🔢 Each number = reported road crashes, 2021–2025
🌊 The bay = empty grid cells
🎨 The colours = field-value conditional formatting on the matrix values

That's the whole trick. ✅

📈 THE DATA IS REAL
• 45,893 crashes across 380 suburbs
• Source: Transport Victoria open road crash data (CC BY 4.0)
• Suburbs: Vicmap locality boundaries, spatially joined to each crash

💡 WHY I LIKE THIS PATTERN
✅ Readability of a map
✅ Control of a table
✅ Exact numbers, every time
✅ Consistent card sizes
✅ Accessible labels
✅ No geography licence required

A "map" in BI is often a layout problem, not a mapping problem. 🧩
